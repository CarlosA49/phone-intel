LEGACY DEMO PAGE · RETIRED
⚠ This page used to fabricate fake owner names.

The original "SMS Locator" demo invented a random "SUBSCRIBER NAME" for every number and presented it as a real lookup. A phone number cannot reveal its owner's identity, so that feature was deceptive and has been removed. Any tool claiming to show a stranger's name or live location from their number is a scam, a breach-data broker, or malware.

✅ WHAT THE REAL TOOL SHOWS (honest, from the number)

  • Country & calling code · registration region (e.g. "San Francisco, CA")
  • Carrier / network operator · line type (mobile / VoIP / landline…)
  • Validity, every number format, timezone & live local clock

❌ WHAT IT WILL NEVER DO

  • Identify the owner's name or address
  • Track a person's real-time / live location

"Region" always means where the number is registered, never where the holder currently is.

▶ RUN THE REAL TOOL

  • Web terminal: python web/app.py then open http://127.0.0.1:5000
  • Terminal (TUI): python -m phone_intel +14155552671
